## Features

**What Features Does The Dzire Offer?**

- Sunroof that doesn't eat into headroom
- Wireless Charging
- Automatic Headlamps
- Push-button Start Stop
- Cruise Control
- Automatic Climate Control
- Rear AC Vent
- If features like the Sunroof and cruise control aren’t appealing to you then the ZXI Variant is still nicely loaded
- 2 type-A and 1 type-C USB fast in addition to a 12v accessory charging ports is adequate.
- Missing features include: front armrest, auto-dimming IRVM, Auto Wipers
- Wireless charging pad doesn’t have cooling vents so phone heats up easily
