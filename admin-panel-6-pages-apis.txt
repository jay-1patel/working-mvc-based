ADMIN PANEL APIs — SIX PAGES
============================

Variables: BASE_URL=http://127.0.0.1:9000, USERNAME=<username>, SESSION_ID=<session>, TENANT_ID=<tenant>, WA_ID=<wa id>, RUN_ID=<run id>.
Protected request headers:
  username: $USERNAME
  session_id: $SESSION_ID
  Content-Type: application/json

1) CHATS
========

1. Load inbox conversations
curl --request POST "$BASE_URL/api/admin/tenants/inbox" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"include_resolved":false}'

2. Load agents
curl --request POST "$BASE_URL/api/admin/tenants/agents" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{}'

3. Load selected conversation
curl --request POST "$BASE_URL/api/admin/tenants/chat/thread" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"wa_id":"$WA_ID","limit":300}'

4. Assign conversation button
curl --request POST "$BASE_URL/api/admin/tenants/inbox/assign" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"wa_id":"$WA_ID","agent_id":"$AGENT_ID"}'

5. Take over / return to bot buttons
curl --request POST "$BASE_URL/api/admin/tenants/inbox/handover" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"wa_id":"$WA_ID","mode":"human"}'
curl --request POST "$BASE_URL/api/admin/tenants/inbox/handover" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"wa_id":"$WA_ID","mode":"bot"}'

6. Resolve conversation button
curl --request POST "$BASE_URL/api/admin/tenants/inbox/resolve" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"wa_id":"$WA_ID","reply":true}'

7. Send reply button
curl --request POST "$BASE_URL/api/admin/tenants/inbox/reply" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"wa_id":"$WA_ID","message":"Hello from admin"}'

8. Upload attachment button
curl --request POST "$BASE_URL/api/admin/tenants/inbox/attach" --header "username: $USERNAME" --header "session_id: $SESSION_ID" --header "Content-Type: application/json" --data '{"filename":"document.pdf","content":"BASE64_FILE_CONTENT","media_type":"application/pdf"}'
